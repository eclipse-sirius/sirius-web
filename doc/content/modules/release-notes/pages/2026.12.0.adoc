= 2026.12.0

== Key highlights




== Breaking changes

- `ISingleClickOnTwoDiagramElementHandler.execute` now takes a `DiagramContext` instead of a `Diagram`.
Custom implementations must reuse the provided context during connector tool execution.
- The `FormEventProcessor` constructor no longer accepts the `representationDescriptionSearchService` parameter of type `IRepresentationDescriptionSearchService`.
Custom factories and subclasses must remove this argument from constructor calls.
- Switch the identifier of libraries from a UUID to a dedicated `LibraryId` type.
This type is now used in the repository, domain services and applications services on the backend.
The GraphQL queries and mutations have also been updated to leverage a matching GraphQL `LibraryId` scalar.
On the frontend, the new id should be treated as an opaque string just like the previous one.
- Diagram layout configurations are now retrieved through the new `DiagramDescription.layoutConfigurations` GraphQL field instead of being hardcoded in the frontend.
The `sirius-components-collaborative-diagrams` module provides the default configurations, applications can implement `ILayoutConfigurationsProvider` to contribute additional configurations.
- Switch to https://github.com/react/react/releases#release-v19.2.8[React 19.2.8]
- Switch to notistack 3.0.2
- Switch to react-draggable 4.7.1
- Switch to https://github.com/ObeoNetwork/react-trello/releases/tag/v2.5.2[@obeonetwork/react-trello 2.5.2]
- Switch to https://github.com/ObeoNetwork/gantt-task-react/releases/tag/v0.7.2[@obeonetwork/gantt-task-react 0.7.2]

== Bug fixes

- Fix an issue where elements filtered by an explorer filter could be rendered for a brief moment during loading.
- Graphical operations such as revealing hidden elements are now applied when executing connector tools.
- Bending points, segment controls and paths share the same geometry while editing rectilinear edges.
- Wrapped labels now fit inside their nodes immediately after using Adjust size.
- Helper lines now appear when resizing a node containing children from the left or top.
- Tables embedded in the Details view can now be edited.
- Bending points on rectilinear edges now take priority over line segments when dragging.
- Fix an issue where a tool configured with an impact analysis report and defined outside the View DSL was not executed correctly.
- Fix an issue where the loading indicator of the explorer view was not rendered during the whole loading phase.


== New features

- A "Collapse All" action has been added in the explorer.
It allows reducing the selected tree item and all its children recursively.
- The selected explorer description and expanded items are now saved in your browser and restored when you refresh the page or reopen the project.
- The table top toolbar provides an action to dynamically resize the visible row heights to fit the cell contents.
- The table column provides an action to resize a column width to fit the cell contents.


== Improvements

- Support Select cells in View-based tables
- Improve the internationalization of the style customization support with a dedicated infrastructure module
- Applications can contribute diagram layout configurations from the backend to populate the Arrange All menu and configure automatic layout.
Sirius Components provides Flow Layout, Compact Layout and Orthogonal Layout by default.
- Improve refresh performance for large diagrams defined with the View DSL.

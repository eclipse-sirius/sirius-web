== New features

* The diagram toolbar now displays the current zoom level, between the zoom in and zoom out buttons.
Click on it to zoom directly to a predefined level, from 25% to 400%.
When the diagram is too narrow to display all its actions, the toolbar can now be scrolled horizontally instead of overflowing the diagram.
